# DeepSeek Harness Desktop Releases

DeepSeek Harness 桌面客户端(Windows x64)的安装包发布与自动更新源。

## 下载
最新版请到 Releases 页面下载 `DeepSeekHarness-Setup-v{版本}-win10-x64.exe`,
双击覆盖安装即可,无需卸载旧版;数据目录、会话与 API Key 自动沿用。

## 自动更新
客户端 v1.7.0 起会自动检查更新,发现新版本弹通知,由你自己决定是否下载安装。
v1.6.0 及更早版本需手动安装一次 v1.7.0。

## 版本迭代说明
各版本新增/改进/修复见仓库内的 RELEASE-NOTES.md。
